# Очередь редакционной проверки

Команда `npm run editorial:queue` строит локальный отчёт из опубликованных предложений, редакционных дат и структурированных условий каталога. Она включает записи с прошедшим сроком, сроком в ближайшие 30 дней, неизвестными параметрами КАСКО/поездок, внутренней заметкой или неполной ссылкой на источник. Черновики и архивные предложения в очередь не попадают.

Для одинакового отчёта за выбранный день используйте `npm run editorial:queue -- --as-of=YYYY-MM-DD`. JSON-вывод для других внутренних инструментов: `npm run editorial:queue -- --as-of=YYYY-MM-DD --json`.

## Как обработать строку очереди

1. Откройте указанный URL и найдите страницу продукта, действующие правила или официальный документ именно этой программы.
2. Сверьте каждое утверждение в карточке с первоисточником и применимостью к указанной аудитории. Проверьте покрытие, лимиты, франшизу, территорию, исключения, цену и оформление — только если первоисточник это раскрывает.
3. Сохраните неизвестное значение, если подтверждения нет; добавьте внутреннюю причину, что именно отсутствует в открытом источнике или требует уточнения у страховщика.
4. Меняйте `checkedAt` только после фактической содержательной сверки. Если проверена лишь доступность URL, дату не обновляйте.
5. Прогоните проверки данных, сборку, внутренние ссылки, регрессии и браузерные сценарии; перед публикацией сохраните резервную копию и внесите итог в `docs/plan-status.md`.

Отдельная команда `npm run verify:links` опрашивает внешние URL и сообщает HTTP-доступность. Ответ 200 не доказывает, что страница содержит актуальные условия или соответствует продукту. Содержательную сверку выполняет редактор вручную.

## Первый срез — 5 ноября 2026

Команда вернула 11 из 62 опубликованных предложений. Все попали в очередь из-за неизвестных структурированных параметров КАСКО или поездок; просроченных `checkedAt` и сроков в ближайшие 30 дней на этот срез нет. Это очередь для просмотра источника, а не требование непременно заполнить каждое неизвестное поле. Неизвестное остаётся неизвестным, если официальный источник его не раскрывает.

Полный воспроизводимый результат с названиями, датами, причинами и источниками сохранён в [`editorial-queue-snapshot-20261105.json`](editorial-queue-snapshot-20261105.json). Для запуска команды нужны зависимости проекта (`npm ci`); на веб-сервер они отдельно не устанавливаются, отчёт формируется в рабочей копии.
