# История версий

Формат — [Semantic Versioning](https://semver.org/lang/ru/): `MAJOR.MINOR.PATCH`.

- **MAJOR** — ломающие изменения адресов, структуры данных или поведения интерфейса.
- **MINOR** — новые возможности без ломки существующего.
- **PATCH** — исправления и правки данных без новых возможностей.

Версия продукта живёт в `package.json` и попадает в `/version.json` и в подвал сайта.
Версия сборки (`buildId`) считается автоматически и с версией продукта не связана.

## 1.1.0 — 2026-10-23

Дизайн-система, официальные логотипы, анимации, уведомления и обновления без сброса кеша.

### Исправлено

- **Карточки не скрывались при поиске и фильтрации.** Правило `.results__item { display: flex }`
  перебивало атрибут `hidden`. Добавлено правило `[hidden] { display: none !important }`,
  фильтры проверяются по фактической видимости элементов, а не только по счётчику.
- **Добровольные продукты помечались обязательными.** Обязательность перенесена на уровень
  предложения: `offer.obligation` со статусом, объяснением и условием применения. Карточки,
  фильтры и страницы продуктов используют его; категория больше не задаёт статус продукта.
- **Аудитория сохранялась не во всех сценариях.** Сохранение выбора унифицировано для
  переключателя, первого экрана, навигации и мобильного меню; на страницах с явной
  аудиторией сохранённое значение синхронизируется.
- **Пункты мобильного меню исчезали.** Правило `.nav { display: none }` скрывало и настольную,
  и мобильную навигацию. Теперь скрывается только настольная; в меню добавлены разделы
  каталога, работают Escape, `aria-expanded`, `inert` и возврат фокуса.
- **Стрелки в подсказках поиска переставали работать.** Фокус остаётся в поле,
  используется `aria-activedescendant`: стрелки двигают подсветку, Enter открывает вариант,
  Escape закрывает, Tab проходит дальше.
- **Шаги оформления ломались на телефоне.** Inline-стиль с тремя колонками убран,
  сеткой управляет компонент `Steps` через `--steps-cols`, на телефоне шаги идут вертикально.

### Добавлено

- Дизайн-система: токены (`src/styles/tokens.css`), слои стилей и набор компонентов
  в `src/components/ui/`, витрина `/ui-kit/` (закрыта от индексации, вне sitemap).
- Иконки Lucide через `@lucide/astro` с единой картой имён (`src/lib/icons.ts`).
- Официальные логотипы шести страховщиков в `src/assets/logos/` и компонент `CompanyLogo`
  с вариантами compact/default/large/wide/lockup. Реестр источников — `docs/logos.md`.
- Анимации на CSS и Motion Mini: появление первого экрана и секций, мягкий подъём карточек,
  переходы кнопок, подсказки поиска, аккордеон, мобильное меню. Учитывается
  `prefers-reduced-motion`.
- ToastManager с API `toast.success/info/warning/error`, очередью, объединением одинаковых
  событий, паузой при наведении и в скрытой вкладке, отдельным assertive-регионом для ошибок.
- Версионирование: SemVer в `package.json`, `buildId` из версии, коммита и времени сборки,
  `/version.json` с `Cache-Control: no-store`, компактный индикатор версии в подвале.
- Проверка обновлений для открытой вкладки: сравнение `buildId` при загрузке, при возвращении
  на вкладку и раз в 5 минут, одно уведомление с кнопкой «Обновить», без циклов перезагрузки.
- GitHub Actions: типы, сборка, внутренние ссылки, артефакт сборки; внешние ссылки — отдельным
  неблокирующим шагом.

### Изменено

- Astro обновлён до 7.4.2 — закрывает критическую уязвимость (`npm audit` без замечаний).
- Страницы каталога, продукта, компании, поиска и 404 переведены на общие компоненты;
  повторяющиеся inline-стили убраны.
- `README.md` дополнен разделами про UI kit, токены, иконки, логотипы, анимации,
  уведомления, релизы, кеширование и CI.
